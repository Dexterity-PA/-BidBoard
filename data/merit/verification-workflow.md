# Verification workflow

Prioritize unresolved fields that current public official evidence can resolve. Each fully verified listing must support identity, value and renewal, deadline policy, application materials, and eligibility.

A current standing or explicitly recurring policy can support its published rules without a future cycle label. Leave deadlineDate null unless an actual calendar date is confirmed. Historical application forms do not establish current requirements.

Split distinct awards when a grouped directory prevents award-specific verification. Keep the original active overview and route; do not describe an active award family as discontinued.

For remaining gaps, record the precise blocker and a revisit trigger, such as a published application opening, corrected sponsor conflict, or publicly available requirements. Keep those entries partial while waiting. Do not spend each batch repeatedly checking unchanged sponsor-dependent gaps.

The research queue is a priority index, not additional verification. Unassigned entries carry their prior review dates and outcomes.

Before publication, independently check new verified claims, validate source hashes and existing routes, and test the website and production catalog. Count upgrades of existing entries separately from newly separated awards.
